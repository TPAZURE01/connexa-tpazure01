# Fluxo de Trabalho Git — Connexa

## Objetivo
Organizar o desenvolvimento do projeto Connexa, permitindo que os três integrantes trabalhem de forma colaborativa e organizada no GitHub.

## Organização das branches
- `main`: branch principal do projeto.
- `task-XX-descricao`: branches utilizadas para desenvolver tarefas específicas.

## Processo de desenvolvimento
1. Criar uma branch a partir da `main` para cada tarefa.
2. Realizar as alterações necessárias na branch.
3. Registrar os commits com mensagens claras, incluindo `AB#XX` para relacionar o trabalho ao Azure Boards.
4. Abrir um Pull Request para integrar as alterações à `main`.
5. Solicitar a revisão de pelo menos um integrante da equipe.
6. Após a aprovação e as verificações necessárias, realizar o merge.

## Boas práticas
- Evitar alterações diretas na branch `main`.
- Utilizar mensagens de commit descritivas.
- Manter as tarefas atualizadas no Azure Boards.
- Revisar as alterações antes de integrá-las ao projeto.
- Comunicar à equipe as mudanças importantes.
